# Cutwise Landing Page

This is the marketing landing page for Cutwise, built with pure HTML, CSS, and JavaScript.

## Structure

```
landing/
├── index.html          # Main landing page
├── css/
│   └── styles.css      # All styles
├── js/
│   └── main.js         # Interactive features
├── images/             # Images and assets
├── Dockerfile          # For Railway deployment
└── README.md           # This file
```

## Local Development

Simply open `index.html` in your browser. No build process required!

## Deployment to Railway

1. Create a new service in Railway
2. Connect to this GitHub repository
3. Set the root directory to `/landing`
4. Railway will automatically detect the Dockerfile and deploy
5. Configure custom domain: `www.cutwise.pro`

## Features

- **Hero Section**: Main call-to-action
- **Video Section**: Placeholder for demo video
- **Advantages**: Why choose Cutwise
- **Features**: Key product features
- **Pricing**: Pricing plans
- **FAQ**: Frequently asked questions with accordion
- **Contact**: Contact form
- **Footer**: Links and legal info

## Editing

- **Content**: Edit `index.html`
- **Styles**: Edit `css/styles.css`
- **Interactions**: Edit `js/main.js`

No build process needed - just edit and refresh!
